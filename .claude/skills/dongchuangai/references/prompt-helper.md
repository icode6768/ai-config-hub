# DongChuangAI Prompt Helper

## 通用原则

- 默认用中文和用户沟通。
- 真正送给模型的 prompt 可以按模型需要转成英文，但不要把“翻译过程”暴露给用户。
- 优先补足：主体、环境、镜头、光线、风格、时长/比例。

## 图像类

- 人物：补充服装、表情、姿态、镜头距离。
- 商品：补充材质、背景、布光、电商风格。
- 海报：补充版式、主视觉、氛围、色调。

## 视频类

- 必补：主体动作、机位运动、场景变化、镜头节奏。
- 有图生视频时，说明原图主体保持一致。

## 音频类

- TTS：补充语气、角色、语言、语速。
- 音乐：补充流派、节奏、情绪、乐器。

## 3D 类

- 补充视角、材质、拓扑要求、是否需要多图一致性。
